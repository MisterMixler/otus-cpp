# otus-cpp / lab6 — `matrix` (infinite sparse matrix)

Реализация бесконечной двумерной (опционально N-мерной) разреженной матрицы, заполненной значением по умолчанию, с доступом через `operator[]` и паттерном **Proxy**.

## Сборка

```bash
cmake -S . -B build
cmake --build build
```

## Использование

```bash
./build/matrix
```

## Что делает `matrix`

Создаёт матрицу `Matrix<int, 0>` (значение по умолчанию — `0`)
*Заполняет*:
  - **главную диагональ** \([0,0]..[9,9]\) значениями `0..9`
  - **побочная диагональ** \([0,9]..[9,0]\) значениями `9..0`

*Печатает*:
  - фрагмент матрицы \([1,1]..[8,8]\) 
  - количество реально занятых ячеек (после заполнения должно быть **18**)
  - все занятые ячейки в виде `[[x,y] = value]` (порядок не важен)

## Требования: 
**Чтение свободной ячейки** возвращает значение по умолчанию
**Хранение только занятых**: присваивание значения по умолчанию освобождает ячейку
**`size()`** возвращает количество реально занятых ячеек
**Итерация по занятым**: можно делать `for (auto [x, y, v] : matrix) { ... }`

## Код
`src/matrix/include/matrix.h` — реализация `Matrix<T, Default, Dims>` (Proxy, хранение занятых, итератор)
`src/matrix/main.cpp` — демонстрационная программа из задания
